BIRTHDAY GIFT WEBSITE
======================

1. Open index.html in a browser to preview the website.
2. Put your real photos inside:
   assets/images/photo1.jpg
   assets/images/photo2.jpg
   assets/images/photo3.jpg
   assets/images/photo4.jpg
   assets/images/photo5.jpg

3. Put the birthday song here:
   assets/song.mp3

4. Open index.html and edit the "birthday" object near the bottom:
   - finalMessage
   - songName
   - letters: names + messages

The countdown is already set to 7 September 2026.

For GitHub Pages:
- Upload index.html and the assets folder to your repository.
- Make sure the folder names and file names stay exactly the same.
